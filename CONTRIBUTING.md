# Contributing

Issues are welcome: bug reports, errors, questions. Please say what you ran, or the words you said to Claude, what
you expected, what you saw, and the versions of the tools involved. Remove any addresses, names, order numbers and
private text first.

Changes to the code are made by the maintainer; describe what you would change in an issue and it is taken
from there.

Security problems go through a private report, not an issue: see `SECURITY.md`.
